# Data

The dataset is not committed to this repository. Download it and place the CSV files directly in this `data/` folder.

**Dataset:** Brazilian E-Commerce Public Dataset by Olist
**Source:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Download steps
1. Sign in to Kaggle and open the dataset page above.
2. Click **Download** to get the zip file, and unzip it.
3. Check that the nine CSV files sit directly inside `data/`, not in a subfolder.

## Files used by the notebook
| File | Used for |
|---|---|
| `olist_orders_dataset.csv` | Purchase, approval, estimated and actual delivery timestamps |
| `olist_order_items_dataset.csv` | Price, freight, product and seller per line item |
| `olist_customers_dataset.csv` | Customer state and zip-code prefix |
| `olist_products_dataset.csv` | Category, weight and dimensions |
| `product_category_name_translation.csv` | English category names |
| `olist_order_reviews_dataset.csv` | Review score (outcome column only) |
| `olist_order_payments_dataset.csv` | Payment type and instalments |
| `olist_sellers_dataset.csv` | Seller state and zip-code prefix |
| `olist_geolocation_dataset.csv` | Zip-prefix coordinates, for customer–seller distance |

## Files generated by the notebook
Running the *Data Loading* section of `assessment2.ipynb` creates these. They are not committed, and are recreated identically on every run (fixed seed on a deterministic snapshot).

| Folder | Content |
|---|---|
| `orders_ml.parquet` | One record per delivered order (96,203 rows), sorted by `order_id` |
| `train_data.parquet` | 70% training subset (67,274 orders), used in Part A |
| `stream_data.parquet` | 30% streaming subset (28,929 orders), replayed through Kafka by `producer.py` |
